# Uliveto Wedding Planner

Progressive web app for couples marrying at Uliveto Casa della Rocca (Imperia): guests, dates, menu, allergies, experiences, travel estimates, guest list with RSVP, tables and floor plan, checklist with the venue's contract deadlines, budget, PDF.

Hosted with GitHub Pages. Open the site on a phone and choose "Install app" / "Add to Home Screen".
